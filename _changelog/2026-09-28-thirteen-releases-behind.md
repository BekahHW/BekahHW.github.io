description: "I audited all 37 pages of our developer docs against one question: could a capable stranger finish each task without asking us what we meant? The structure held up. The content had drifted thirteen CLI releases, and four findings would have stalled a first customer: the console's Gateways page had no docs at all, the team-onboarding command in the docs took an email address the server does not accept, two documented commands no longer parse, and the skills guide taught a lifecycle the product had since inverted. Every command claim is now checked against the shipped binary's --help output, which is the check I should have been running all along."
