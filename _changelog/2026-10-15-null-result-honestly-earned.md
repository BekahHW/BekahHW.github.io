description: "Every correction an engineer gives a coding agent lands in the session record next to everything the agent saw before it went wrong, which makes it a training example. I read 593 full team sessions and confirmed 1,049 pushback events, 512 of them genuine agent corrections. The top causes were technical errors, failing to use context already in the session, and misreading intent; the dramatic failures like thrashing barely registered. Then I fine-tuned a 27B model on 153 accepted turns and had a blind judge score it against the base on 124 held-out cases. Base passed 41%, the fine-tune 39%, intervals overlapping. In the twenty cases I hand-read, the two models made the same first move nine times. The dataset is the asset. The first training run was tuition."
