description: "I read through Remotion's published skill library, 71 skills, to steal design patterns for ours. The best ones treat the description as a router: capability plus 'use when,' with literal error messages as triggers, and negative triggers ('use only when') to suppress the agent's default instincts. Reliability shows up as ritual: verify after every write, distrust success signals, document the failure fingerprints and never just the happy path. The library behaves like a codebase, with a call graph, CI that validates links, and governance written down as a skill itself."
